개인정보처리방침

시행일 및 최종 수정일: 2026년 10월 8일

이 방침은 Dayveranda 제작 도구가 Google OAuth 및 YouTube API를 통해 사용하는 데이터와 이 소개 사이트에 적용됩니다. 현재 제작 도구는 운영자가 본인의 YouTube 채널을 관리하는 개인용 도구입니다.

1. 사용하는 정보

운영자가 Google 승인 화면에서 허용한 경우, YouTube 채널 ID와 채널 이름, 업로드한 영상의 ID·제목·설명·공개 설정·처리 상태·썸네일 업로드 결과를 사용합니다. 작업 수행에 필요한 OAuth 접속 토큰과 갱신 토큰도 보관합니다. Google 비밀번호, 결제 정보 또는 Gmail 내용은 수집하지 않습니다.

2. 사용 목적과 권한

youtube.upload 권한은 완성된 음악 영상과 썸네일을 승인한 채널에 업로드하는 데 사용합니다. youtube.readonly 권한은 연결된 채널을 확인하고 업로드한 영상의 상태를 조회하는 데 사용합니다. 현재 업로드 기본 설정은 비공개입니다. 계정 연결을 승인해도 이 소개 사이트에서 다른 사용자의 계정으로 자동 로그인되지는 않습니다.

3. 보관과 보호

인증 정보는 운영자가 관리하는 PC의 공개 웹 폴더 밖에 있는 전용 인증 폴더에 저장합니다. 업로드 기록은 작업을 이어서 처리하고 중복 업로드를 방지하기 위해 보관합니다. 토큰과 인증 정보는 공개 소스 저장소나 영상 설명에 게시하지 않으며, 가사·음악 생성용 AI 프롬프트에 전달하지 않습니다.

4. 공유와 제한된 사용

Google 및 YouTube API 데이터는 계정 확인과 승인한 업로드 작업에 사용합니다. 이 데이터를 판매하거나 광고 목적으로 사용하지 않습니다. Google에서 받은 정보를 다른 서비스로 전송하는 경우에도 제한된 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다. 승인한 업로드 과정에서는 영상·썸네일과 게시 정보를 Google/YouTube에 전송합니다.

5. 보관 기간과 삭제 요청

인증 정보는 연결을 유지하는 동안, 업로드 기록은 작업 복구에 필요한 동안 보관합니다. 인증 정보와 기록 삭제는 아래 연락처로 요청할 수 있습니다. PC에 보관된 정보 삭제와 이미 YouTube에 업로드된 영상 삭제는 별개이며, 영상은 YouTube Studio에서도 직접 관리할 수 있습니다.

6. 연결 해제

Google 계정의 서드 파티 연결 관리에서 Dayveranda 접근 권한을 삭제할 수 있습니다. 권한을 삭제하면 이후 API 작업은 새 승인을 받기 전까지 진행할 수 없습니다. 권한 삭제만으로 PC에 남은 업로드 기록이 자동 삭제되지는 않으므로, 보관 정보 삭제가 필요하면 연락해 주세요.

7. 이 소개 사이트

이 사이트는 GitHub Pages에서 제공하는 정적 소개 페이지입니다. Dayveranda는 이 페이지에 분석 도구, 광고 또는 자체 로그인 기능을 설치하지 않았습니다. 호스팅 제공자는 사이트 제공과 보안을 위해 접속 정보를 처리할 수 있으며, 해당 처리는 GitHub 개인정보처리방침에 따릅니다.
